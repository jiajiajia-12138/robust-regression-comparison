# OLS 与四类稳健回归估计的比较：蒙特卡洛模拟 + 真实数据实证

比较一元线性回归中 OLS 与 LAD、Huber M 估计、MM 估计、LTS 四类稳健估计的表现，
回答一个实际问题：**什么时候必须放弃 OLS？该用哪种稳健方法？**

配套课程论文：《基于 LAD、Huber、MM、LTS 四类稳健估计方法的一元稳健回归》
（论文本身不在本仓库公开）。

## 内容

1. **蒙特卡洛模拟**（`R/01_monte_carlo_simulation.R`）
   - 模型 y = β0 + β1·x + ε，真实参数 β0 = β1 = 1，x ~ U(0, 5)，n = 100，重复 M = 1000
   - 6 种误差情景：正态 / 拉普拉斯 / t(3) / t(5) / 混合正态 0.95N(0,1)+0.05N(5,100) / 柯西
   - 评价指标：β0、β1 估计的偏差（bias）与均方误差（MSE），重点看 β1 的 MSE
   - 结果输出到 `results/mse_simulation.csv`

2. **真实数据实证**（`R/02_empirical_cars.R`）
   - R 内置 `cars` 数据集：50 辆汽车的车速与刹车距离
   - 五种方法估计 + OLS 标准化残差诊断 + 单点污染实验（第 50 号观测的 dist 增加 60）
   - 生成 `figures/fig2_cars_fits.png`

3. **离群点演示**（`R/03_figure1_outlier_demo.R`）
   - 95 个正常点 + 5 个 y 方向离群点，展示 OLS 拟合线被拉偏、LAD/Huber 基本不受影响
   - 生成 `figures/fig1_outlier_demo.png`

## 复现

依赖 R (≥ 4.0) 及三个扩展包：


## 主要结果

模拟（β1 的 MSE，节选自论文 Table 1，M = 1000）：

| 方法 | 正态 | t(3) | 混合正态 | 柯西 |
|------|------|------|----------|------|
| OLS | **0.00484** | 0.01357 | 0.03679 | 79.31068 |
| LAD | 0.00720 | 0.00943 | 0.00875 | 0.01323 |
| Huber | 0.00506 | 0.00768 | 0.00638 | 0.01803 |
| MM | 0.00510 | **0.00756** | **0.00580** | 0.01506 |
| LTS | 0.00682 | 0.00955 | 0.00727 | 0.01339 |

- 正态误差下 OLS 最优（符合高斯–马尔可夫定理），但柯西下 MSE 膨胀 4 个数量级（79.31），彻底失效；
- 全部非正态情景下四种稳健方法的 MSE 均小于 OLS，**MM 综合表现最好**；
- 混合正态（5% 强离群点污染）下 MM 的 MSE（0.00580）仅为 OLS 的约 1/6。

实证与污染实验（cars 数据，n = 50）：

- 数据干净时五方法结论一致（斜率介于 3.40～3.93）；
- 仅将 1 个观测的 y 值增加 60：OLS 截距由 -17.58 偏移至 -22.85、斜率由 3.93 升至 4.35；
  Huber 变化约为 OLS 的三成；**LAD 完全不变，MM/LTS 变化不足 0.11（斜率）**。

## 结论

误差近似正态、数据干净时直接用 OLS；分布未知或怀疑有离群点时用 **MM 估计**
（约 50% 崩溃点 + 95% 渐近效率）；怀疑离群点比例很高时用 LTS。
